# Uji Astro Blog

Blog minimal berbahasa Indonesia untuk menguji alur kerja ChatGPT → GitHub → Cloudflare Pages.

## Menjalankan secara lokal

- Gunakan Node.js 22 atau lebih baru.
- Jalankan `npm install`.
- Jalankan `npm run dev` untuk mode pengembangan.
- Jalankan `npm run build` untuk membuat website statis di folder `dist`.

## Cloudflare Pages

- Framework preset: Astro
- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`

Artikel contoh saat ini didefinisikan di `src/data/posts.js`.
